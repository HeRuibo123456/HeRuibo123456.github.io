P1775 石子合并（弱化版）

题目大意

这道题讲的是有一堆石子，每相邻两堆石子可以合并，求最小的合并代价

题目思路

这道题可以用区间 DP来做

所谓区间DP，通常是由一个区间的状态转移到另一个区间。做此类的题目，一般都是有"删除"/"插入"之类的字眼。

我们可以先设状态。设dp[i][j]为从第i堆石子合并到第j堆石子所用的最小合并代价, sum(i, j)为从a[i]加到a[j]的总价值,则状态转移方程为dp[i][j] = min(dp[i][j], dp[i][k] + dp[k + 1][j] + sum(i, j)); 。同时，我们可以发现，需要对区间[i,j]求和，所以我们可以用上前缀和优化。可以得到一个时间复杂度为O(n^3)的算法。

代码

#include<iostream>
#include<cstring>
#define MAX 302 
using namespace std;

int n, a[MAX], dp[MAX][MAX];

int main() {
	cin >> n;
	for(int i = 1; i <= n; i++) {
		cin >> a[i];
		a[i] += a[i - 1];
	}
	memset(dp, 0x3F, sizeof(dp));
	for(int i = 1; i <= n; i++) {
		dp[i][i] = 0;
	}
	for(int i = 2; i <= n; i++) {
		for(int l = 1; l <= n - i + 1; l++) {
			int r = l + i - 1;
			for(int j = l; j < r; j++) {
				dp[l][r] = min(dp[l][r], dp[l][j] + dp[j + 1][r] + a[r] - a[l - 1]);
			}
		}
	}
	cout << dp[1][n] << endl;
	return 0;
}
