P1077 [NOIP 2012 普及组] 摆花

题目大意

有n种花要拿m桶，第i桶只能拿ai桶，求总方案数对106+7取模

题目思路

本题是一道简单的计数题，这是我做过的第一道计数DP

我们先设状态，设dp[i][j]表示前i种拿j桶的方案数，则状态转移方程为： dp[i][j] = ∑dp[i - 1][j - k] mod 106+7;

所以这道题其实是非常简单的

代码

#include<iostream>
using namespace std;

const int MAX = 102, mod = 1000007;
int a[MAX], n, m, dp[MAX][MAX];

int main () {
	cin >> n >> m;
	for(int i = 1; i <= n; i++) {
		cin >> a[i];
	}
	
	dp[0][0] = 1;
	for(int i = 1; i <= n; i++) {
		for(int j = 0; j <= m; j++) {
			for(int k = 0; k <= min(j, a[i]); k++) {
				dp[i][j] = (dp[i][j] + dp[i - 1][j - k]) % mod;
			}
		}
	}
	
	cout << dp[n][m];
	return 0;
}
